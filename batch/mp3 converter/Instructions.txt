INFO
  - Converts files: .m4a and .opus into .mp3
  - Encodes at constant bitrate 320 kbps (highest standard quality for MP3)
  - Original files are not deleted; you will have two files per track (source + .mp3)
  - Skips any file where an .mp3 with the same name already exists

REQUIREMENTS
  - FFMPEG installed and available in PATH
  - .m4a and/or .opus files to convert

HOW TO USE
  - Put any2mp3.bat in the same folder as your .m4a/.opus files
  - Double-click it to convert everything to .mp3 (320 kbps CBR)
