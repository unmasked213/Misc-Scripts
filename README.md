# Misc-Scripts

A collection of utility scripts for Windows automation, media processing, and system management.

## Batch Scripts

**[clean_ghosts.bat](batch/clean_ghosts.bat)** - Cleans up duplicate AI assistant and browser processes

**[any2mp3.bat](batch/mp3%20converter/)** - Converts audio files to MP3 format

## Python Scripts

**[Duplicate Image Detection](python/Duplicate%20image%20detection/)** - Find and remove duplicate or similar images

**[Media Stats](python/media_stats/)** - Analyze your image and video collections

**[Minimize Windows](python/minimize_windows/)** - Automatically minimize specific windows

**[Mimic Keystrokes](python/Mimic%20keystrokes%20%28auto%20typing%29/)** - Simulate realistic human typing

**[Home Assistant Dashboard Launcher](python/ha_dashboard_launcher/)** - Display Home Assistant dashboard in a standalone window

**[List Files by Folder](python/create_list_of_filenames/)** - Generate organized lists of your files

---

*Each script folder contains detailed instructions for setup and usage.*
